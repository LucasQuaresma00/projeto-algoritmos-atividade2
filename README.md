## Descrição

Este repositório contém a implementação das duas questões da Atividade 2, utilizando estruturas de dados fundamentais estudadas na disciplina.

### Questão 1 - Verificação de Palíndromo

Implementação de uma pilha para verificar se uma cadeia de caracteres é um palíndromo.

### Questão 2 - Sistema de Danceteria

Implementação de filas para controlar a formação de pares na pista de dança, respeitando a ordem de chegada dos participantes.
